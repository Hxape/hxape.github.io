Manage GitHub tokens

Add new token

A token lets this browser read repositories you can access on GitHub. Choose a fine-grained personal access token:

  1. On GitHub, choose Hxape as the resource owner and select the repositories you want to read.
  2. Grant repository Contents: Read-only, set an expiration, then generate the token. Organization approval may be required.
  3. Copy the token into this form. GitHub displays it only once.

Protect the saved token

The token is encrypted with this password before it is saved on this device. Enter it again to unlock the token. The password is not saved.

The token is encrypted with a key from your passkey. If the passkey is lost or unsupported, add the token again or use password storage.
