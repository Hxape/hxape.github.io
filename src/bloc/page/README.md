# Оформление и размещение страницы

Блок. Выбирает оконный вид и место единственных настроек, сохраняет открытость нижнего блока и подсказок. Ведёт привязки окон, наблюдение адреса и копирование; передаёт готовые подписи и обработчики представлениям, сохраняя состояние при переносе в PiP.

Отражает размещение настроек и доступность группы информации в `html[data-preferences-placement]` и `html[data-information-open]` каждого нынешнего окна. Читает прежние Preferences и Panel; собственного просмотра не хранит. Перенос, открытие, закрытие и временный возврат к каталогу обновляют эти признаки через прежний срок привязок. CSS передаёт условное скрытие нижних дублей в ShadowRoot, не удаляя кнопки.

`html[data-header-pointer-over]` и `html[data-header-focus-visible]` отражают наведение и видимый клавиатурный фокус верхнего бара. После нажатия указателем обычный фокус не сохраняет раскрытие общих Search/Bookmarks/LinkMode. Тексты подсказок берутся из одной команды и обновляются вместе с общим режимом ссылок.
