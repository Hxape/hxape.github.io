# Каталог проектов

Обогащает дерево сведениями о проектах, разрешениями и адресами GitHub. Хранит выбор, загрузки, кэши и ревизию доступа; передаёт запросы просмотра панели.

Обычная команда `.haxelib` начинает отменяемый переход до ожидания сети. Смена строки, фокуса или доступа отменяет продолжение; `default_branch` определяется внутри подготовки панели. Явные ref ссылок, истории и закладок сохраняются. Готовый исходник прежнего просмотра можно использовать повторно только при совпадении файла, ref, снимка и действующего доступа; обновление выполняет полное чтение.

Удержание и Enter строки файла передают панели признак применения закреплённого вида следующих открытий. E в дереве сохраняет прежний последний выбор, а явная строка и переход в исходник продолжают выбирать SOURCE CODE.

`search.mjs` ведёт отдельный поиск загруженных узлов, включая свёрнутые ветви, и собственную историю запросов с обменом JSON. Он использует общий компонент поиска и не загружает данные ради запроса. ProjectCatalog выбирает найденную строку и применяет отдельный режим раскрытия из преференсов. Временное раскрытие прекращается при уходе от совпадения или закрытии; ручные ветви и текущий путь истории сохраняются.
