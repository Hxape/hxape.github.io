# Настройки сайта

Блок. Сохраняет тему, цвета, размер текста, флаги значков, время удержания и подсветки строки, местный корень организации, общий режим ссылок и выбор раскрытия дерева истории; передаёт готовые данные и обработчики организму настроек. SitePreferences применяет оформление к основному и PiP документам и сохраняет состояние при переносе.

`organizationRoot` изначально пуст, `linkMode` изначально `internal`. `cycleLinkMode()` выбирает `internal → vscode → github`; пустой корень исключает `vscode`. Пути POSIX и диска Windows проверяются и нормализуются до записи в localStorage. Очистка корня снимает VS Code до уведомления потребителей. События `organization-root-change` и `link-mode-change` передают нынешние значения; изменения другой вкладки перечитываются из хранилища. Абсолютный путь не включается в данные сайта.

Удержание кнопки режима отмечает `data-hold-ready` после общего порога и отправляет `organization-root-open` только при отпускании. Движение, отмена или перенос снимают готовность; последующий короткий click подавляется. Приложение открывает прежнюю временную область Panel с `organizationRootControl`: готовая модель той же молекулы, действия `saveOrganizationRoot` и сброса. Черновик остаётся в input; путь, проверка и localStorage принадлежат Preferences. Подпись нынешнего режима и подсказка `navigationTooltip` совпадают с панелью.

Модель пути используется также в обычном меню настроек. Сохранение и очистка показывают подготовленные значки externaldrive с aria-label и подсказкой; очистка меняет только местную настройку браузера.

Search использует тот же единственный жест удержания меню: порог отмечает готовность, отпускание отправляет `search-history-open` в Panel, а release-click подавляется только у прежней кнопки. Короткое нажатие отправляет `search-open`; клавиши и подсказки показывают F/M. Preferences не хранит запросы и не управляет их списком.

`historyTreeMode` возвращает `none`, `temporary` либо `always`; отсутствие или неверная запись выбирает `temporary`. Значение хранится скаляром в `site-history-tree-mode`, проверяется перед чтением и изменением и передаётся событием `history-tree-mode-change`. Catalog получает getter через приложение и владеет раскрытием ветвей; настройка не создаёт другой текущий материал. Отказ сохранения показывается рядом с полем, изменения другой вкладки перечитываются.

`sourceHighlightDuration` возвращает `0`, `500`, `1000`, `1500`, `2000`, `2500`, `3000` миллисекунд либо `null` для бесконечности. Без достоверной записи используется `3000`; `0` снимает фон сразу, `null` оставляет без таймера. Ползунок меню цветов показывает только индекс этой шкалы. В `site-source-highlight-duration` хранятся строки миллисекунд либо `infinity`; отсутствующая запись не смешивается с бесконечностью. Изменение передаётся событием `source-highlight-duration-change` и синхронизируется с другой вкладкой. Визуальный срок применяет SourceRequest; адрес, закладки и место чтения здесь не меняются.

События `bookmarks-open` и `search-open` передают действия DocumentPanel через приложение. Кнопки доступны и при закрытой панели; хоткеи принадлежат панели. История открывается через `H` или удержание переходов панели. `C` обновляет материал, цвета открываются своей кнопкой.

На компьютере копии переходов появляются вместе с остальными верхними настройками по наведению или фокусу. В нижнем размещении M/N скрываются лишь при доступных действиях открытой информации в этом документе, а без неё возвращаются; узлы сохраняются. PageAppearance передаёт это условие CSS через `html[data-*]` и наследуемый параметр.
