# Просмотр документов

Обогащает панель документами, HXDoc и исходниками. Хранит текущий просмотр, историю, вкладки и отмену загрузок; сохраняет их при переносе в Picture-in-Picture.

При отказе подготовки хранит для явного повтора только проверенный адрес и параметры перехода. Новый повтор заново проверяет доступ; неуспех не создаёт просмотр или запись истории. Временные области остаются поверх native dialog при смене ширины и переносе, сохраняя форму, фокус и прокрутку.

Подготовка PiP закрывает обычные действия по `moving`. Защищённый `resume` возвращает привязки таблиц и уже принятого отображения, фокус, адрес, рисунок поиска и остаток срока строки до общей фиксации. Готовый исходник синхронно проверяет CSS, уже загруженный координатором; его Text и frame сохраняются без скрытия и повторного чтения. `commit` завершает только не бросающие присваивания; при отказе возобновления таблицы ещё доступны для отката в исходное окно.

Если первый SOURCE открывается уже в PiP, SourceRequest до приёма текста готовит через прежний SourceShell CSS также исходного командного документа. Каждый ожидаемый шаг проверяет поколение, сигнал и фактического владельца host; возврат готового raw домой не начинает сетевую загрузку стиля.

SourceRequest ведёт только визуальный срок полосы выбранной строки: 0 снимает её сразу, null сохраняет без таймера. Перенос продолжает оставшийся срок в новом окне; истечение запускает затухание полосы за 360 мс и не меняет строку, адрес, закладку или место чтения. Перетаскивание держит полосу до завершения, затем действует текущая настройка Preferences.

Переход между позициями текущего готового исходника сохраняет Text, frame и оболочку после свежей проверки адреса и доступа каталогом. Другой ref/файл/доступ и явное перечитывание используют полную подготовку. Размер шрифта пересчитывает только геометрию полосы, сохраняя её срок и погашенное состояние.

Journal хранит правила all/merge/unique, паузу автоматического сбора, предел, запреты репозиториев и именованные группы закладок. Принятый view связан с конкретным id истории: незаписанный материал не перезаписывает прежний cursor. Объединение меняет только нынешний вход файла, восстановление — только cursor; очистка отменяет непринятый restore, сохраняя материал и закладки. Закрепление DOCUMENTATION/SOURCE/last меняет только default обычного Hold/Enter файла, отдельно от нынешней вкладки и последнего выбора.

Поиск файла принадлежит Panel и может работать одновременно с поиском каталога. Оба используют общий компонент с разметкой `public/html/search.html`, но разные экземпляры SearchState из `src/common/search/state.mjs`. История файла отдельно выгружается и загружается через JSON без изменения текущего запроса и сбора. Пассивный SearchState хранит единственные latest, режим сбора и MRU до 50 точных запросов; Panel фиксирует завершение при Enter, переходе к совпадению или явном закрытии. Встроенная полоса сохраняется между файлами и за временными списками. Удалённый нынешний черновик не возвращается при одном закрытии без нового использования. DOM-проекция, числовое выделение и один Range рисунка существуют только для нынешнего текста/окна; новый текст/вид/отзыв/перенос освобождает их, а тот же ready Text сохраняет проекцию.
