# Доступ GitHub

Octocat хранит открытый PAT и выполняет разрешённые запросы; `GithubAccess` владеет закрытыми снимками, текстовым кэшем и отзывом доступа. Ответы JSON и сообщения канала проверяются как `unknown` до использования полей.

Подтверждённый отказ чтения `401` или `denied` очищает снимок и закрытый текст, уведомляет каталог и другие вкладки и помечает зашифрованную копию отозванной. Токен, ревизии и исходный снимок сверяются до отзыва: запоздалый ответ не меняет новый доступ. Сеть, ограничение частоты и `404` отдельного файла сохраняют прежний успех; отсутствие служебного закрытого снимка остаётся отдельным случаем его проверки.
