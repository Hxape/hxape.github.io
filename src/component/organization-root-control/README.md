# Путь организации

Молекула. Выводит форму местного каталога организации, пояснение и сообщение об отказе. Проверка, сохранение и режим ссылок остаются у SitePreferences.

Обычное меню сохраняет прежний `onChange`; оба размещения получают одну модель `save`/`reset` и готовые `saveIcon`/`resetIcon`. Кнопки показывают только значки externaldrive с подтверждением либо сбросом; доступные подписи и подсказки сохраняются. Сброс очищает настройку браузера и не удаляет каталог. Черновик остаётся в input; `id` разделяет поле и подписи разных размещений. Отказ проверки показывается также нативной ошибкой поля; отказ записи возвращает готовое сообщение владельца.
