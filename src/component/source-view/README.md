# Просмотр исходного текста

Показывает готовый текст с номерами строк, припиской и состоянием; выделяет и прокручивает выбранную строку. Не загружает файл или оболочку.

Номера остаются одним текстовым узлом. Нажатую строку определяет по координате; готовые метки закладок рисует перед номером вне потока. Колонка имеет постоянную для нынешнего файла ширину. Клавиатурное действие колонки связывает владелец просмотра.

Организм: область исходного текста соединяет текст, номера строк, метки, приписку и состояние чтения.

Метки являются отдельными кнопками с увеличенной невидимой областью захвата; номера остаются одним PRE. Локальный жест передаёт координаты после половины высоты строки и подавляет его завершающий click. Свободную строку, удаление за столбцом и изменение metadata решает Panel/Journal; компонент не читает записи или текст ради жеста.

Видимость полосы задаётся готовым boolean-атрибутом `data-source-highlight` на frame; её срок хранит SourceRequest. Снятие полосы сохраняет семантический номер `data-selected-line`. Постоянный нижний отступ номера и кода оставляет последнюю строку над полосой прокрутки, не добавляя текстовую строку.
