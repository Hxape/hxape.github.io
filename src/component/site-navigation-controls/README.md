# Управление переходами сайта

Молекула. Выводит кнопки закладок, поиска и режима ссылок, доступные при закрытой панели просмотра. Получает готовые подписи, значки и обработчики; не хранит режим или журнал. История открывается клавишей H или удержанием переходов панели.

Подсказка на самом button составляется одной `navigationTooltip` из имени действия, читаемой подписи клавиш и необязательного пояснения удержания. `shortcut` сохраняет физические клавиши для aria-keyshortcuts; `shortcutLabel` позволяет показать F/M в подсказке. Жест режима или поиска передаётся владельцу через подготовленные обработчики; порог, отмена, показ поля пути/списка запросов и подавление click принадлежат Preferences.
