# Содержимое документа

Показывает текст либо очищенный Markdown, внутренние якоря и изменяемые таблицы. Относительные ссылки разрешает переданная функция.

После очистки сохраняет исходное значение ссылки для переданного обработчика. Якорь разрешается по исходному имени; порождённый DOM-id не входит в адрес. Режим ссылок можно обновить без повторного преобразования Markdown и пересоздания таблиц.

Организм: область документа соединяет безопасную разметку, ссылки, якоря и управление таблицами.
