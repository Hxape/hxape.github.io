# Действия переходов

Показывает доступность перехода назад, вперёд и обновления, а также готовый режим ссылок.

Молекула: управление переходами отражает готовую доступность и режим ссылок на прежних кнопках.

Стрелка остаётся доступной для открытия виджета удержанием, даже если обычный шаг или список отсутствуют; `data-step-available` отражает именно шаг. Удержание связывает владелец панели. Отдельное готовое действие истории между стрелками и обновлением имеет собственный знак, подпись и доступность: ручное добавление/удаление файла либо разрешение/исключение репозитория из автоматического сбора; null скрывает только его. Знак режима ссылок меняется в прежнем месте кнопки; раскрытие меню не подключено.
