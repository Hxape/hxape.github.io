# Время подсветки строки

Молекула. Показывает дискретный ползунок, выбранный срок и сообщение сохранения. Получает готовые индекс, подписи, необязательный знак бесконечности и действие владельца.

Передаёт строку индекса через `onInput`; не переводит её в миллисекунды, не обращается к хранилищу и не ведёт срок подсветки. Preferences готовит значение и сохраняет выбор, SourceRequest применяет визуальный срок. Доступный текст range и output объясняет бесконечность, декоративный знак не заменяет это название.
