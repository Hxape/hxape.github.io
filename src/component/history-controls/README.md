# Настройки сбора истории

Молекула. Показывает автоматический сбор, выбор политики, учёт смены вида и предел. Получает готовые значения, подписи и действия Journal через Panel.

При выключенном сборе скрывает только дополнительные поля. Очистку показывает компонент коллекции в шапке истории независимо от открытости настроек. Компонент не хранит настройки, не объединяет записи и не меняет курсор. Внешний ввод передаётся владельцу для проверки.
