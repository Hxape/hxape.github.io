# Закладки

Показывает готовые закладки списком либо деревом. Адреса, порядок и представление хранятся у панели.

Организм: область закладок соединяет выбор именованной группы, список или дерево её записей и действия над ними через компонент коллекции.

Имя материала остаётся сверху. В пояснении готовые значки стоят перед именем репозитория и относительным путём; доступное имя сохраняет вид материала.

Готовые `bookmarkGroups` задают выбранную группу, подтверждение её удаления и режим правого действия строки. Начальный режим — удаление, при нескольких группах доступен перенос. Форма передаёт создание, переименование и обмен JSON владельцу. Panel подготавливает только строки выбранной группы, поэтому перестановка остаётся в её пределах. Записи и имена групп хранит Journal.

При ожидающем удалении строка получает оставшиеся секунды и действие отмены; сроком и освобождением таймера владеет Panel. Значки репозитория и пути центрируются по первой физической строке соответствующего текста, включая переносы.
