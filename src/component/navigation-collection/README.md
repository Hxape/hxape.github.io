# Список переходов

Показывает готовые строки списком либо деревом. Передаёт открытие, удаление, закладки и перестановку владельцу; снимает жест перед заменой или переносом.

Организм: временная область соединяет заголовок, список или дерево, сообщения и действия записей.

`controlsOpen` задаёт видимость полей заголовка; без значения они видны. Переключатель передаёт `toggleControls` владельцу и сообщает открытость через `aria-expanded`. Очистка истории находится в шапке и недоступна при пустом списке.

В области закладок передаётся одно удаление записи. Кнопка истории добавляет или удаляет закладку адреса, сохраняя саму запись истории. Контур или заливка показывают обычное состояние; при наведении существующая закладка получает знак удаления.

Готовые значки строки заменяют видимые слова вида в истории и закладках; доступное имя сохраняет имя, репозиторий, вид и путь. Строка без подготовленных значков показывает переданные текстовые пояснения.

История группируется по готовым `repository/ref/fileKey`; `fileName` и `fileIcon` относятся к физическому файлу, а значок самой строки может обозначать метод или поле. Native details хранит только местное раскрытие представления. Значки заголовков клонируются для показа и не переносят DOM-узел из строки. Группы закладок приходят готовыми; компонент передаёт выбранные id в действия владельца и не сохраняет их.

Временная форма обмена JSON заменяет список до применения или отмены. Она получает готовые подписи, черновик, режим объединения/замены и подтверждение; текст и намерения возвращает Panel. Справа в закладке одна ячейка удаления либо нативного выбора группы. Отсчёт удаления приходит готовым и не создаёт таймер в представлении.
