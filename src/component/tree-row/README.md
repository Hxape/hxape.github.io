# Строка дерева

Показывает готовые имя, значок и приписку строки и обозначает недоступное действие. Выбор и правила доступа задаёт вызывающая сторона.

Молекула: строка соединяет готовое имя, знак, приписку и доступное действие; приписка конечного узла стоит рядом с native button, чтобы ссылки не вкладывались в кнопку.
