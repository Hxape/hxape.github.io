# Преференсы

Организм. Составляет единый popup темы, размера текста, цветов, значков, длительности удержания, местного каталога организации и раскрытия дерева истории. Разметка находится в public/html/preferences.html и читается при открытии; значения, действия и повтор загрузки получает от SitePreferences.
