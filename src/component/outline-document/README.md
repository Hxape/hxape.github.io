# Структурированный документ

Показывает секцию с готовыми заголовком, текстом и дочерними представлениями без обхода предметной модели.

Заголовок получает готовый адрес и действие перехода к объявлению; режим ссылок определяет вызывающий блок.

Организм: секция документации соединяет заголовок, текст и уже подготовленные дочерние секции.
