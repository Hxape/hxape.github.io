# Приписка дерева

Очищает строчную разметку по переданной политике и оставляет только ссылки HTTP(S). Поиск приписки по предметным данным выполняет вызывающая сторона.

`showCaptionLinkIcon` добавляет или удаляет один пустой носитель значка ссылки. Каталог классифицирует её назначение, CSS рисует маску и тень вне потока; исходный текст, адрес и политика очистки сохраняются.

Молекула: приписка строки соединяет безопасный текст, ссылки и готовые носители их значков.
