# Панель просмотра

Работает с готовым каркасом панели: областями содержимого, состоянием, текстовым пояснением и действием вида. Для Markdown это переключение HTML/текста; для Haxe готовый знак и подпись политики следующего обычного открытия. Историю, политику и загрузку ведёт вызывающая сторона.

Организм: оболочка чтения соединяет области документа, исходника, состояния и управления их представлением.
