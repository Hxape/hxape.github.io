# Раскрытие дерева

Молекула. Показывает готовый выбор раскрытия при переходах истории или поиске каталога. Получает отдельный id, пункты и пояснение от Preferences; возвращает выбранный скаляр для проверки и сохранения. Не хранит режим и не управляет ветвями. Поле связано с label, статус показывает отказ сохранения.
