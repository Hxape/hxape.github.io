# Форма поиска

Организм. Показывает форму поиска и отдельный список готовых запросов от владельца поиска файла или каталога. Форма `role="search"` содержит `type="search"`, счётчик справа от поля и действия справа: очистку, предыдущее/следующее совпадения, область выделения файла, сбор запросов, историю и закрытие. Поле занимает оставшуюся ширину; его стиль совпадает с полями преференсов. Лупа занимает отдельную левую ячейку вне input: нажатие в неё не переводит фокус полю. `embedded` выбирает полосу внутри документа; без материала Panel показывает прежний popup. Разметка формы, истории и обмена JSON загружается из `public/html/search.html`. Два контейнера имеют разные id ввода и действуют независимо; выбор выделения скрыт для каталога.

`renderSearch(container, model, actions)` возвращает input для фокуса. Номер совпадения задан владельцем: от 1, либо 0 при отсутствии. Поле передаёт полный запрос; его стрелки выбирают прежние запросы, стрелки сфокусированных кнопок — совпадения. Enter вызывает prepared `submit`, Shift+Enter идёт к предыдущему совпадению. `clear` удаляет нынешний запрос из поля и истории, поэтому явная кнопка заменяет браузерный cancel. Готовые `collecting`, `selectionOnly` и `canSelection` отражаются в кнопках; компонент не читает Selection, не вычисляет совпадения и не хранит query.

`renderSearchHistory(container, model, actions)` экспортируется из того же входа и реализован в `history.mjs`. Показывает готовые строки MRU, нынешний latest, сообщения хранения и действия выбора/удаления/закрытия. Запрос не превращается в MaterialTarget; удаление строки не меняет latest само по себе. Явный повтор хранения передаётся владельцу. Выгрузка и загрузка JSON используют действия владельца; компонент хранит только временный черновик отдельно для каждого контейнера. `resetSearchHistory` освобождает его при закрытии. Тексты файла, Range, совпадения, сохранение и порядок MRU остаются у соответствующего владельца.

`bindSearchDrag(popup, signal)` из `drag.mjs` переносит временный popup только по Y после смещения на 15 CSS px. Захват начинается в счётчике, левой области лупы или прозрачных полях формы вокруг ввода. Их `touch-action: none` не является свойством предка input; ввод и очистка сохраняют нативное поведение. Делегирование popup переживает обновление формы; завершитель и сигнал снимают жест, слушатели и `--search-drag-y`, положение не сохраняется. Panel связывает этот срок с показом поиска и переносом окна.
