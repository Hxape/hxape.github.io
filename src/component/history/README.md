# История

Показывает подготовленные записи истории и передаёт действия владельцу журнала.

Организм: область истории соединяет настройки сбора, раскрываемые группы репозитория/ref/файла и действия записей через компонент коллекции. Файловые группы изначально свёрнуты, поэтому последовательность строк одного файла не занимает весь список. Заголовки получают отдельные копии готовых значков; значки самих записей не перемещаются.

Panel передаёт готовые `historyControls`, открытость блока и действия настройки. Кнопка в шапке скрывает весь блок вместе с исключениями; очистка остаётся в шапке. Выключенный сбор сохраняет показанные записи и скрывает только дополнительные поля. Правила all/merge/unique, учёт вида и предел хранит Journal.

Раскрываемый список `historyExclusions` показывает подготовленные подписи и возвращает id действию `unblockRepository`. Он доступен также при выключенном сборе; снятие запрета относится только к будущей автоматической истории и не меняет GitHub-доступ.

Получает признак ожидающего удаления и действие отмены; запись остаётся доступной для открытия. Срок удаления и его принятие принадлежат панели, а не представлению списка.

Действия со значком лотка передают выгрузку и загрузку всей истории владельцу. Временная форма JSON показывает готовый текст и подтверждение; проверку адресных записей и поисковых запросов выполняют их прежние владельцы до принятия.
