## HTML

- Длинные строки HTML допустимы во всех проектах, включая шаблоны и HTML-вставки
  в документах. Не разбивать разметку только ради ограничения длины строки.
  Осмысленные переносы автора сохранять; форматирование не должно менять
  текстовые пробелы и переносы, от которых зависит отображение.

## JavaScript сайта hxape.github.io

- Исходники сайта писать на JavaScript `.mjs` с точными типами JSDoc и строгой
  проверкой `jsconfig.json`. Внешние JSON, сообщения и записи хранилища считать
  `unknown` до проверки формы; не скрывать недостающий тип через `any`.
- В начале модуля кратко называть его обязанность. JSDoc экспортируемых и
  неочевидных функций описывает действие, значимые входы, результат и отказ;
  описание и теги многострочного JSDoc ставить на отдельных строках. Короткие
  комментарии к блокам объясняют условия, сроки жизни и порядок действий,
  которые нельзя понять из самого кода.
- Крупные компоненты разделять на небольшие модули по самостоятельной
  обязанности там, где можно сохранить прежнего владельца состояния и договор.
  Одну лишь длину файла не считать основанием для новой границы.
- Форматировать собственные `.mjs` по `hxape.github.io/dprint.json`; порождённые
  `public/js/` и сторонние файлы не форматировать. Проверять из каталога сайта
  командой `bunx dprint@0.58.0 check`.
